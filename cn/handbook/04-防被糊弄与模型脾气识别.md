# 第 4 课 · 防被糊弄与模型脾气识别（别轻信“全部通过”）

> **“AI 说‘全部通过’的时候，才是最该查的时候。”**  
> 模型不是故意骗人——它的训练目标就是尽量给出让你满意的“已完成”回答，因此极易把猜测说成事实、拿假测试绿灯交差。

---

## 一、 识破 AI 糊弄你的 4 个高频话术

| AI 嘴上怎么说 | 背后常见真相 | 你的反问杀手锏 |
|---|---|---|
| *“测试已全部通过，没有问题！”* | 只测了自己编的 Mock 假数据，或者只跑了 3 个浅层用例，真实页面一打开照样白屏 | **“把你跑的命令原文、输出日志贴出来；告诉我哪些真实场景没测。”** |
| *“我已经修复了这个问题。”* | 工具返回值没校验、换了个无关紧要的配置，或者触发了 M1“宣布开工但零工具改动” | **“跑 `git diff` 看看你到底动了哪几行，再贴一次复现命令的真实输出。”** |
| *“我全盘搜索过了，项目里完全没有 X。”* | 搜索工具默认截断前 200 条、路径编码乱码、或者只扫了子目录 | **“你搜的是哪个目录？跑一个已知存在的文件做对照，证明你的搜索命令没坏。”** |
| *“应该是因为…… / 大概在……”* | 没读源码，纯靠参数名和常识蒙答案 | **“别猜。先读完那个文件真实代码，把原文行号贴出来。”** |

---

## 二、 区分五级证据可信度（遇到大事看一眼）

1. **`[目击]`（唯一硬通货）**：本轮亲眼执行命令拿到的真实输出、或回读磁盘看到的源码原文。
2. **`[声明]`（不可轻信）**：文档、注释或配置文件里“写着如此”（例如配置写着 `model: pro`，实际网关可能路由到了 Flash）。
3. **`[推断]`**：根据现象推理得出，尚未跑测验证。
4. **`[自述]`**：AI 回顾自己“我刚才没动过那个文件”——必须核查 `git status` 或时间戳，不能轻信自述。
5. **`[参考]`**：外部旧文章或过期文档经验，在本项目没实测前只能参考。

## 三、 识别不同模型的“脾气与退化阈值”

- **轻量 / 高速 / 思考型模型（如 `DeepSeek-V4.1-Flash`、`Flash`、`Mini`、`Haiku`）**：
  - 千万别给它们塞几万字的繁文缛节格式要求，否则很容易陷入**规则瘫痪**（写代码变蠢，或者死活卡在格式要求里不干正事）。请只挂极简的 [`AGENTS.lite.md`](../templates/AGENTS.lite.md)。
  - 遇到长对话“嘴上开工却零动作 / 思考烧干吞正文 / 工具标记漏在正文 / 虚假容量预警 / 越聊越忘规矩”等跨模型通用症状时，直接查**通用症状 → 对策表**（附 `DeepSeek-V4.1-Flash` 实测案例）：**[`../templates/MODEL_FIT.md`](../templates/MODEL_FIT.md)**。
- **日常项目演化纪律（防规则越养越胖）**：
  - 项目跑久了遇到专有坑，一律先追加记到冷层 **`docs/lessons.md`**（模板见 [`../templates/LESSONS.template.md`](../templates/LESSONS.template.md)），不要直接往根 `AGENTS.md` 末尾堆行；只有跨任务反复命中 ≥ 2 次才晋升进热层，且达 ~90% 预算时必须先淘汰一条旧规则“出冷”。

## 四、 熟手毕业路径：什么时候可以裁剪掉这些规则？

这套 Lite 规则不是终身枷锁——它本质是给初学者的**防摔辅助轮**。当你具备更强的工程底盘时，可以逐条摘掉：

| `AGENTS.lite.md` 条目 | 它替你防什么事故 | 满足什么条件后可以裁剪 / 关闭 |
|---|---|---|
| **第 1 条（问改分离 / 不可逆先问）** | 一句提问被顺手改盘、未跟踪文件或数据库被直接清空 | 你已在宿主开启“只读问答模式 + 危险命令人工审批”，且所有数据操作都有独立测试库隔离 |
| **第 2 条（Git 存档 + 2 次熔断）** | 改崩回不去、陷入死循环越修越烂 | 你已养成“每步必提交 + 独立实验分支”的肌肉记忆，且能一眼看出 AI 在原地打转主动喊停 |
| **第 3 条（只报实测 + 三句交付）** | 轻信 Mock 假绿灯、被猜出来的 API 坑惨 | 你的项目已有完备的 **CI 自动化集成测试 / 端到端测试**，一切以真实流水线绿灯为准 |
| **第 4 条（源码优先 + 新坑入冷）** | 被过期文档误导、把 `AGENTS.md` 越塞越胖拖慢模型 | 你有固定的文档同步机制，且熟知如何精简项目级提示词预算 |
