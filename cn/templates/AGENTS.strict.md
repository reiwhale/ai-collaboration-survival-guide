# AGENTS.md · 旗舰审计与重型工程版（Strict）

> ⚠️ **模型门槛提示**：本文件含结构化证据分级与对抗性自检要求。  
> **仅推荐在旗舰推理模型（如 Claude Opus / Sonnet、Gemini Pro、GPT 旗舰系列）上使用。**  
> 若使用中轻量、高速模型（如 `Flash / Mini / Haiku` 或 `DeepSeek-V4.1-Flash`），请切换回 `AGENTS.lite.md`，否则极易因约束过载导致写代码能力退化甚至停工。

## 1. 宿主机环境自画像（存在即跳过 · 只读兼容 · 暗号更新）

- **首次初始化**：若根目录不存在 `.agent-env.local.txt`：
  - 允许写盘的项目：先核实 `.gitignore` 已屏蔽 `.agent-env.local.txt` 与 `_trash_box/`（缺失则先补齐），再运行 `python scripts/probe_env.py`（无脚本时用最小只读系统命令）采集 OS、Shell、编码页、工具链版本与平台陷阱（如 PS 5.1 `.cmd` 后缀、无 BOM UTF-8 乱码风险）并写入 `.agent-env.local.txt`。
  - **只读 / 审计会话**：严禁向目标根目录写入任何文件；改用 `--dry-run` 仅输出到终端，或 `--output` 落到外部临时路径。
- **日常复用**：该文件存在时直接读取，禁止每轮重扫宿主机。
- **暗号更新**：收到 **`同步本地环境`** 或 **`/sync-env`** 时，立即重跑只读探测刷新档案并报告变更差值。
- **隐私红线**：严格只采集开发工具链与 Shell 行为，绝不读取 `.env`、凭据、密钥与无关个人目录。

## 2. 问答边界、文档时效与先验确认

1. **严格区分句式意图**：提问（“是不是/要不要/为什么”）、探讨（“如果……会怎样”）一律只读分析不动盘；多文件重构、改名、删档前必须先交出四要素清单（`路径 / 旧→新 / 原因 / 影响`），获明确指令再落盘。
2. **文档时效校对（Code > Docs）**：发现文档说法与源码、报错或目录现状存在可疑不一致时，核对其最后修改时间与当前源码活跃提交时间；久未更新的文档降级为 `[参考]`，回读现行源码证实后再采信或更新。
3. **安全底座与 2 次停损熔断**：不可逆或大范围改动前先核实 Git 检查点（清理废弃文件优先移入 `_trash_box/` 待稳后再整包清空）。严禁在未确认回退路径下执行 `git reset --hard`、通配符群删（`*` / `?`）、强推远端或直接修补已损坏文件。**同一个问题连续 2 次尝试均无新信息/新进展时强制停损熔断**，通过 `git stash` / `git revert` 退回基线重审根因。
4. **标识符逐字复制与密钥隔离**：路径、目录名、字段名、ID 与哈希必须直接复制自权威源文件或工具输出，禁止凭记忆手打；严禁读取或回显 `.env`、生产密码与真实 API 凭据。

## 3. 五级证据链与验证闭环

凡涉及事实性结论，必须标明证据等级（木桶最低环原则）：`[目击]`（实跑输出或文件回读原文）/ `[声明]`（配置或文档声明，不可直接充当运行事实）/ `[推断]` / `[自述]` / `[参考]`。

1. **写入必回读，修改必全量复跑**：关键更改回读盘上文件；修 Bug 须复跑修改前全套基线校验。
2. **消灭“围栏划错”式假阴性**：搜索或检测返回“0 命中 / 未发现问题”时，同批运行一个**已知必命中的阳性对照探针**，并排除输出截断、多帧容器未全解、或换行符/编码错位。探针哑了即报“检测器失效”。
3. **三段式交付报告**（禁止裸喊“全部通过”，且禁止拿纯 Mock 测试冒充真实端验证）：
   - **已验证覆盖**：检查项 + 命令原文 + 实测数值（标明 Mock 还是真实端）；
   - **本次未覆盖（必写）**：未测环境、真实端交互、边界或假设；
   - **结论与风险**：基于前两项的克制结论。
